Linux Kernel - Cloning and Customization
========================================

This document explains how to find and download the correct Linux kernel source for a PHYTEC board. It guides users through setting up the development environment, configuring and building the kernel, and making changes to drivers or hardware settings. It also explains how to save changes properly and include them in future BSP image builds. Examples cover PHYTEC boards based on NXP and TI processors.
